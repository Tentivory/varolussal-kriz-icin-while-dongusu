# Varolussal Kriz İçin While Döngüsü

## Önsöz

Bu repository, insanlık tarihinin en derin varoluşsal sorularından birini ele almaktadır: **While True: neden?**

Bilim insanları, filozoflar ve çay demleyen yazılımcılar yüzyıllardır bu sorunun peşinde koştu. Bu proje, o soruya bilimsel, matematiksel ve tamamen ciddi bir cevap sunmaktadır.

## Özellikler

- **Gerçekten sonsuz**: Program çalıştığında durmaz. Ctrl+C bile yetmeyebilir (denemeyin).
- **Felsefi derinlik**: Her iterasyonda yeni bir varoluşsal kriz üretir.
- **Performans**: CPU'nuzu %100 kullanmaz, sadece ruhunuzu yorar.
- **Güvenlik**: Hiçbir şey güvenli değil. Hayat da değil.

## Kurulum

```bash
git clone https://github.com/Tentivory/varolussal-kriz-icin-while-dongusu.git
cd varolussal-kriz-icin-while-dongusu
python3 kriz.py
```

**Uyarı**: Bu kodu çalıştırmadan önce hayatınızı gözden geçirin. Belki bir kahve molası alın. Belki iki.
